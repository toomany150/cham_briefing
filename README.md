# 🏢 네이버 부동산 VIP 매물 브리핑 PPT 생성기 & 크롤러

네이버 부동산의 **매물 번호(10자리)** 또는 매물 URL을 입력하면, 단지 내 불필요한 수십~수백 건의 전체 매물 목록 대신 **해당 매물 1건에 집중된 16:9 와이드스크린 [VIP 고객 브리핑용 파워포인트(PPTX)]** 발표 자료를 단 하나의 파이썬 파일로 즉시 자동 생성합니다.

---

## 📌 주요 특징

1. **단 하나의 파이썬 파일 (`naver_land_crawler.py`)로 모든 작업 완결**:
   - 외부 의존성 분산 없이 단일 파일로 동작합니다.
2. **매물 단건 집중 분석**:
   - 단지 내 수많은 매물 리스트는 과감히 제외하고, 고객 브리핑에 필요한 **오직 해당 매물 1건의 제원과 가격(전세승계 실투자금 갭 계산 포함)**을 정밀 분석합니다.
3. **웹 검색 및 지능형 입지 보완 데이터 연동**:
   - **개발 호재 및 미래 가치**: 부전역 복합환승센터(KTX/동해선/경전선), 시민공원 촉진 재정비구역(촉진3, 2-1 등), 범천 철도차량정비단 이전
   - **학군 상세**: 부암초 안심 초품아 도보 통학로, 주변 중고교, 부산국제고/한국과학영재학교 및 학원가 연계
   - **단지 기본 제원**: 총 세대수, 준공일(입주년도), 총 주차대수(세대당), 시공사, 난방방식
   - **교통망 및 편의시설**: 부암역/부전역 대중교통, 이마트트레이더스/롯데마트 더블 마세권, 부산시민공원 도보 숲세권, 종합병원
4. **프리미엄 16:9 비즈니스 슬라이드 디자인 (총 7장)**:
   - **Slide 1**: VIP 브리핑 표지 (단지명, 동, 매물번호, 실투자금 배지)
   - **Slide 2**: 매물 핵심 제원 및 가격 분석 (희망가, 갭투자금, 면적, 층/향, 옵션, 중개사)
   - **Slide 3**: 단지 기본 제원 (총 세대수, 준공일, 주차대수, 시공사, 난방방식)
   - **Slide 4**: 개발 호재 및 미래 가치 (부전역 환승센터, 촉진지구, 철도정비단)
   - **Slide 5**: 학군 상세 및 교육 환경 (초품아, 명문 중고교, 글로벌빌리지, 학원가)
   - **Slide 6**: 교통망 및 생활 편의시설 (지하철/버스, 더블 마트, 시민공원, 병원)
   - **Slide 7**: 종합 브리핑 결론 및 VIP 투자의견 (투자 포인트 3대 요약)

## 🛠 설치 및 실행 방법

### 1. 필수 라이브러리 설치
```bash
pip install httpx openpyxl python-pptx
```

### 2. 기본 실행 (대화형 입력)
```bash
python naver_land_crawler.py
```
> 실행 시 터미널에 다음과 같이 매물 번호 입력창이 나타납니다:
> ```text
> =======================================================
>  🏢 네이버 부동산 VIP 매물 브리핑 PPT 생성기
> =======================================================
> 브리핑 자료를 생성할 10자리 매물 번호(또는 매물 URL)를 입력하세요
> [기본값: 2650717046]: 
> ```
> 엔터를 누르면 기본 예시 매물(`2650717046`)의 PPT가 즉시 생성되며, 다른 매물번호를 입력하면 해당 매물의 PPT가 생성됩니다.

### 3. CLI 한 줄 명령 실행
```bash
# 매물 번호 지정 실행 (예: 2650717046)
python naver_land_crawler.py 2650717046

# 매물 웹 URL 지정 실행
python naver_land_crawler.py "https://new.land.naver.com/articles/2650717046"
```

## 📊 출력 파일 안내
- **결과 파일 형식**: 파워포인트 프리젠테이션 (`.pptx`, 16:9 와이드스크린)
- **파일명 규격**: `네이버부동산_VIP브리핑_{매물번호}_{단지명}_{생성일시}.pptx`
- **활용 방안**: 고객 상담 시 태블릿/모니터 브리핑, 인쇄 출력, PDF 변환 후 카카오톡 전송 등
